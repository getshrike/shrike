# Illustration credits

The three animated isometric SVGs in this directory are adapted from
SketchValley's free animated illustration library ([sketchvalley.com/motion](https://sketchvalley.com/motion)):

| File | SketchValley illustration |
| --- | --- |
| `pr-orphan-delta.svg` | Data analysis |
| `verified-batches.svg` | Deployment pipeline |
| `deterministic-engine.svg` | Gauge meter |

License: free for personal and commercial use, no attribution required.
Modification and recoloring are allowed; the originals may not be resold or
redistributed as a standalone product. See
[sketchvalley.com/license](https://sketchvalley.com/license/).

Changes made for Shrike:

- Recolored to the warm-monochrome palette on `#08090A` (no blue, red, or
  green from the originals).
- Scene labels rewritten for the product: `DIFF SCAN` / `ORPHAN`,
  `VERIFIED`, and `CHECK 72MS`.
- Animation stays CSS-only inside each SVG. The files need no JavaScript and
  honor `prefers-reduced-motion`.
