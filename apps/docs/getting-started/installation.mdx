---
title: "Installation"
description: "Install the getshrike npm package, verify the CLI, and resolve the native engine on a supported platform."
---

Shrike requires Node.js 22 or newer. The npm package is `getshrike`; it installs two equivalent commands, `shrike` and `getshrike`.

<Note>
  You do not need a Rust toolchain to use the published npm package. A native engine binary is installed for your platform as an optional dependency.
</Note>

## Prerequisites

- Node.js 22 or newer. Check it with `node --version`.
- A package manager that installs optional dependencies normally.

## Install

<CodeGroup>

```bash npm
npm install -D getshrike
```

```bash pnpm
pnpm add -D getshrike
```

```bash yarn
yarn add -D getshrike
```

</CodeGroup>

The install adds the `shrike` and `getshrike` bins to the project. Each run resolves a native engine in this order:

1. `SHRIKE_ENGINE` — an explicit path to an engine binary.
2. A repository build at `target/release/shrike-engine` or `target/debug/shrike-engine` (source checkouts only).
3. The installed platform package for your OS and CPU.
4. A `shrike-engine` binary on `PATH`.

Published platform packages are `getshrike-linux-x64`, `getshrike-linux-arm64`, `getshrike-darwin-x64`, `getshrike-darwin-arm64`, and `getshrike-windows-x64`. Packaged binaries are verified against a SHA-256 sidecar before every run, not only at install time; a missing or mismatched sidecar fails closed with exit `4` and tells you to reinstall. The launcher does not silently fall back to `PATH` in that case.

## Verify the installation

```bash
npx shrike version
```

Expected output: `shrike 1.0.1 (protocol 1.0)`. Add `--json` to get the name, version, protocol version, and engine as JSON.

## If the engine is missing or incompatible

If a command exits `4` with `shrike-engine was not found` or an unsupported-platform message:

1. Reinstall with optional dependencies enabled — for example, `npm install -D getshrike` rather than an install with `--omit=optional`.
2. Confirm your OS and CPU are one of the five platform targets listed above.
3. If you are working from a source checkout, run `cargo build -p shrike-engine` and let the CLI find `target/debug/shrike-engine`, or point `SHRIKE_ENGINE` at the binary explicitly.
4. Re-run `npx shrike version`.

The last two steps are for source builds only. An npm install should not require Rust.
